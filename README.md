# 各種マイクロサービスとツール

## ディレクトリ構成

```
go/ <- goマイクロサービス
node/ <- nodeマイクロサービス
python/ <- pythonマイクロサービス
soketi/ <- soketi起動用
wordpress/ <- ヘッドレスCMS用wordpress

selenium/ <- セレニウム

documents_go/ <- goマイクロサービスのドキュメント
documents_node/ <- nodeマイクロサービスのドキュメント
documents_python/ <- pythonマイクロサービスのドキュメント
documents_soketi/ <- soketi関連のドキュメント

memo_*.txt <- 機能ごとの作業用のメモ
memo.txt <- 作業用のメモ
```

## 機能

- soketi(Pusher互換のWebSocketサーバー)
- PythonのAIサーバー
- ヘッドレスCMS用wordpress
- GoのWebSocketサーバー
- NodeのWebSocketサーバー
